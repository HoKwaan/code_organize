@@ eio-d3-sec1-2
소프트웨어 PWM 루프의 뼈대다. 시작할 때 `clock_gettime(CLOCK_MONOTONIC, &next)` 로 현재 시각을 잡고, 켠 뒤 끌 시각(next + on_ns)까지, 끈 뒤 다음 주기 시작(next + PERIOD)까지 `clock_nanosleep(…, TIMER_ABSTIME, …)` 으로 절대 시각을 정해 잔다. usleep 처럼 상대 시간으로 자면 자고 깨는 시간과 코드 실행 시간이 매 주기 쌓이지만, 절대 시각은 하나가 늦어도 다음 목표가 밀리지 않는다.

@@ eio-d3-sec1-3
예제 01 은 쓰레드로 200 Hz 소프트웨어 PWM 을 만들고, 깨어날 때마다 목표 시각보다 얼마나 늦었는지(jitter)를 히스토그램으로 보여 준다.
- 인자: 숫자는 듀티(%), `-b` 는 숨쉬기(0→100→0), `-f` 는 SCHED_FIFO 실시간 우선순위(2교시).
- `record()`: 늦은 ns 를 10 · 50 · 100 · 500 · 1000 µs 경계로 나눠 6칸 히스토그램에 넣고 횟수 · 합 · 최대를 갱신한다. 메인 쓰레드와 함께 쓰므로 mutex 로 보호한다.
- `ts_add()`: timespec 에 ns 를 더하고 10억 ns 를 넘으면 초로 올린다.
- `sleep_until()`: 절대 시각까지 `clock_nanosleep(TIMER_ABSTIME)` 으로 자고, 깨어난 시각 − 목표 시각을 기록한다.
- `pwm_thread()`: 주기마다 on_ns = 5ms / 100 × 듀티 만큼 켜 두고 끈다. 다음 주기 시작은 "지금" 이 아니라 이전 시작 + 주기라 누적 오차가 없다. 듀티 0 이면 켜지 않고, 100 이면 끄지 않는다.
- `-f` 일 때: `mlockall` 로 메모리를 묶어 페이지 폴트로 멈추지 않게 하고, 쓰레드 속성에 SCHED_FIFO 우선순위 50 을 준다. 권한이 없으면 EPERM 과 함께 setcap 명령을 안내한다.
- 메인 루프: 20 ms 마다 돌며 숨쉬기면 듀티를 1% 씩 바꾸고, 100번(2초)마다 지연 히스토그램을 # 막대(최대 40칸)로 출력한 뒤 초기화한다.
- 끝나면 쓰레드를 join 하고 LED 를 끈 뒤 반납한다.

@@ eio-d3-sec1-8
빈칸 1-1 의 정답이다.
- 빈칸 ① `on_ns`: 끌 시각 = 주기 시작 + 켜짐 시간이다.
- 빈칸 ② `MONOTONIC`: 단조 시계(CLOCK_MONOTONIC) 기준으로 잔다.
- 빈칸 ③ `TIMER_ABSTIME`: 절대 시각으로 자야 한 주기가 늦어도 다음 목표 시각이 밀리지 않는다.
- 빈칸 ④ `PERIOD_NS`: 다음 주기의 시작은 "지금" 이 아니라 이전 시작 + 주기로 계산한다.

@@ eio-d3-sec1-t1
PWM 용어표다. 주기(period)는 한 번 켜졌다 꺼지기까지의 시간(ns · µs · ms), 주파수는 1초에 몇 주기인지로 1 / 주기(Hz), 듀티(duty cycle)는 주기 중 켜져 있는 시간(ns) 또는 비율(%)이다. MCU 과목에서는 ESP32 LEDC 하드웨어가 파형을 만들었고, 오늘 1~2교시는 쓰레드로, 3교시부터는 Pi 하드웨어 PWM 으로 만든다.

@@ eio-d3-sec1-t2
상대 시간과 절대 시각 sleep 비교표다. `usleep(on); usleep(off);` 처럼 상대 시간으로 자면 1만 주기 뒤 매 주기 수십 µs 씩 밀려 전체가 늦어진다. `clock_nanosleep(TIMER_ABSTIME)` 으로 절대 시각까지 자면 하나가 늦어도 다음 목표는 그대로라 누적 오차가 없다.

@@ eio-d3-sec1-t3
소프트웨어 PWM 이 흔들리는 원인 표다. SCHED_OTHER 쓰레드는 다른 프로세스와 CPU 를 나눠 써서 스케줄링 지연이 생기고, 깨우는 타이머 신호 자체가 수십 µs 늦을 수 있으며, 처음 쓰는 메모리에 접근하면 커널이 페이지를 준비하느라 멈춘다(페이지 폴트).

4. TIMER_ABSTIME 을 주면 절대 시각으로 자서 누적 오차가 없다.

@@ eio-d3-sec2-4

@@ eio-d3-sec2-6
빈칸 2-1 의 정답이다.
- 빈칸 ① `mlockall`: 현재와 앞으로 쓸 메모리를 RAM 에 고정해 페이지 폴트로 멈추지 않게 한다.
- 빈칸 ② `EXPLICIT`: `PTHREAD_EXPLICIT_SCHED` 를 주지 않으면 attr 의 정책이 무시되고 main 의 SCHED_OTHER 를 물려받는다.
- 빈칸 ③ `SCHED_FIFO`: 실시간 정책. 권한이 없으면 pthread_create 가 EPERM 을 돌려주므로 setcap cap_sys_nice 가 필요하다.

@@ eio-d3-sec2-t1
스케줄링 정책 비교표다. 기본 SCHED_OTHER 는 CFS/EEVDF 로 모두에게 조금씩 공평하게 나눠 준다. SCHED_FIFO(우선순위 1~99)는 실시간 정책으로, 깨어나면 즉시 돌고 스스로 양보할 때까지 계속 돌며, 우선순위가 높은 쪽이 무조건 먼저다.

@@ eio-d3-sec2-t2
SCHED_FIFO 를 쓰는 호출 표다. `pthread_attr_setschedpolicy(&at, SCHED_FIFO)` 로 정책을, `pthread_attr_setschedparam(&at, &sp)` 로 우선순위 50 을 정하고, `pthread_attr_setinheritsched(&at, PTHREAD_EXPLICIT_SCHED)` 를 빼면 위 설정이 무시되고 부모 정책을 물려받는다. `mlockall(MCL_CURRENT | MCL_FUTURE)` 는 메모리를 RAM 에 고정해 페이지 폴트로 멈추지 않게 한다.

@@ eio-d3-sec3-1
셸에서 sysfs 로 하드웨어 PWM 을 직접 조작한다.
- `cd /sys/class/pwm/pwmchip0`: pwm-2chan overlay 가 만든 PWM 칩 폴더로 간다.
- `cat npwm`: 채널 수(2).
- `echo 0 > export`: 채널 0 을 사용자에게 내보내 pwm0 폴더를 만든다.
- `echo 1000000 > pwm0/period`: 주기 1 ms(값은 ns 단위) = 1 kHz.
- `echo 200000 > pwm0/duty_cycle`: 켜짐 0.2 ms = 20%.
- `echo 1 > pwm0/enable`: 출력을 시작한다. LED 가 어둡게 켜진다. 900000 으로 바꾸면 밝아진다.
- `echo 0 > pwm0/enable`, `echo 0 > unexport`: 출력을 끄고 채널을 돌려준다.

경보기 확인 항목 표다. 손을 가까이 할수록 삑 간격이 짧아지는 것은 간격 = 거리 × 10 ms 이기 때문이다. 부하(yes × 4)를 걸어도 부저 음정 · 서보 위치가 흔들리지 않는 것은 하드웨어 PWM 이 파형을 만들기 때문이다. 다만 측정 쓰레드와 메인 루프는 일반 쓰레드라 반응이 조금 늦어질 수 있다. 10 cm 경계에서 서보가 떨리지 않는 것은 3회 중앙값이 튀는 값을 걸러 주기 때문이며, 더 안정하게 하려면 히스테리시스를 넣는다(도전 과제).

@@ eio-d3-sec8-t4
Day 3 정리표다. PWM 은 주기 · 듀티로 평균 전력을 조절한다. 소프트웨어 PWM 은 절대 시각으로 자도 부하 앞에서 jitter 로 흔들리고, SCHED_FIFO · mlockall 은 흔들림을 크게 줄이지만 setcap 권한과 주의가 필요하다. 하드웨어 PWM(/sys/class/pwm)은 한 번 쓰면 칩이 정확히 유지하며 2채널이다. 서보는 펄스 폭, 패시브 부저는 주기로 정보를 준다. L293D · 릴레이는 GPIO 가 신호만 주고 큰 전류 · 다른 회로는 드라이버 · 접점이 맡는다. 스테퍼는 순서표 · 스텝 수 · 가감속, HC-SR04 는 Echo 5V 분압 + 커널 타임스탬프 + 중앙값이 핵심이다.

@@ eio-d3-sec8-p8-2
1. 측정 함수가 Echo 를 최대 60 ms 기다리는 동안 부저 박자를 놓치지 않도록 쓰레드를 나눴다.
2. 두 쓰레드가 함께 쓰는 g_cm 은 mutex 로 보호한다.
3. 파형은 PWM 회로가 계속 만들고 프로그램은 값만 바꾸므로 부하에도 음정이 흔들리지 않는다.
4. 켜는 기준과 끄는 기준을 다르게 두어 경계에서 떨지 않게 하는 것이 히스테리시스다.

@@ eio-d3-pdf-p18-1
슬라이드 p.18 의 alarm.c 메인 루프 핵심이다. mutex 로 g_cm 을 읽고, 50 cm 이상은 초록(2), 20 이상은 노랑(1), 그 아래는 빨강(0)으로 zone 을 정해 LED 셋 중 하나만 켠다. 10 cm 미만이면 연속음, 50 cm 미만이면 거리 × 10 ms 간격으로 삑을 정하고, 상태가 바뀔 때만 부저 enable 과 서보 duty(0° 또는 90°)를 쓴다. 20 ms 마다 반복한다. yes × 4 부하에도 음정 · 서보 위치는 하드웨어 PWM 이라 그대로이고 반응만 조금 늦을 수 있다.
