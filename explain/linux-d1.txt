@@ linux-d1-sec2-1
기본 파일 조작 명령이다.
- `mkdir -p test/a/b`: 중간 디렉터리까지 한 번에 만든다.
- `touch test/hello.c`: 빈 파일을 만든다 (있으면 수정 시각만 갱신).
- `cp 원본 대상/`: 복사.
- `mv 이전 새이름`: 이름 변경 또는 이동.

@@ linux-d1-sec2-2
파일에 실행 권한을 준다. `ls -l` 맨 앞 `-rw-r--r--` 은 종류(-: 일반 파일) 다음 rwx 세 묶음이 차례대로 소유자 · 그룹 · 그 외 권한이다. `chmod +x run.sh` 로 모두에게 실행(x) 권한을 더하면 `-rwxr-xr-x` 가 되고 `./run.sh` 로 실행할 수 있다. 실행 권한이 없으면 Permission denied 가 난다.

@@ linux-d1-sec2-3

- `grep processor /proc/cpuinfo | wc -l`: cpuinfo 에서 processor 줄만 골라 줄 수를 세면 코어 수다.
- `ps aux | grep -v grep | grep bash`: 모든 프로세스 목록에서 grep 자신(-v 로 제외)을 빼고 bash 가 든 줄만 찾는다.

@@ linux-d1-sec2-4

- `sleep 30 &`: 끝에 & 를 붙이면 백그라운드로 돌고 프롬프트가 바로 돌아온다.
- `jobs`: 이 셸의 백그라운드 작업 목록.
- `echo $!`: 방금 백그라운드로 띄운 프로세스의 PID.
- `kill %1`: 작업 번호 1 을 종료한다 (% 는 작업 번호, 숫자만 쓰면 PID).

@@ linux-d1-sec3-1
Day 1 공통 Makefile 이다. 폴더의 모든 .c 를 각각 같은 이름의 실행 파일로 만든다.
- `CC = gcc`, `CFLAGS = -Wall -Wextra -g` 는 컴파일러와 옵션 변수다 (-Wall -Wextra 경고 최대, -g 디버그 정보).
- `SRCS = $(wildcard *.c)` 는 모든 .c 파일 목록, `TARGETS = $(SRCS:.c=)` 는 거기서 .c 를 지운 실행 파일 이름 목록이다.
- `all: $(TARGETS)` 이 첫 규칙이라 그냥 `make` 하면 전부 빌드한다.

@@ linux-d1-sec4-1
printf 출력이 커널까지 가는 경로 그림이다. 사용자 모드의 `printf()` 는 먼저 glibc 의 stdio 버퍼에 모았다가 `write()` 래퍼를 부른다. 래퍼가 `syscall` 명령(write 번호 1)을 실행하면 CPU 가 커널 모드로 바뀌어 `sys_write()` 가 터미널 드라이버로 글자를 보낸다. 시스템 콜은 `man 2`, C 라이브러리 함수는 `man 3` 에 설명이 있다.

@@ linux-d1-sec4-2

- `getcwd`: 현재 디렉터리 경로를 얻는 함수 (도전 과제: 프롬프트에 표시).
- `SIGCHLD`: 백그라운드(&) 실행 도전 과제에서 좀비를 남기지 않게 처리할 시그널.
- `open`: > 리다이렉션 도전 과제에서 출력 파일을 여는 호출.
- `dup2(fd, 1)`: 연 파일을 fd 1(표준 출력) 자리에 복제해 리다이렉션한다 (Day 4 예고).
- `SIG_IGN`: 시그널 무시.
- `SIG_DFL`: 시그널 기본 동작.
- `fgets`: 한 줄 입력. NULL 이면 Ctrl+D.
- `NULL`: 인자 배열 끝, strtok 이어 자르기 인자.
- `strtok`: 문자열을 구분자로 자르는 함수.
- `chdir`: 빈칸 정답. 셸 위치를 바꾼다.

@@ linux-d1-src-01_write_vs_printf.c
예제 01 원본 소스 파일이다. `write(1, …)` 은 바로 커널에 쓰고, `printf` 5줄은 stdio 버퍼에 쌓였다가 write 로 나간다. 터미널이면 줄 단위, 파이프 · 파일이면 블록 단위 버퍼링이라 파이프로 보내면 printf 5줄이 write 한 번으로 합쳐지고 write 문장보다 늦게 나온다. return 0 으로 끝나도 exit 과정에서 fflush 된다. `strace -e trace=write` 와 `strace -c` 로 관찰한다.

@@ linux-d1-src-02_syscall_direct.c
예제 02 원본 소스 파일이다. glibc 래퍼 `getpid()` 와 `syscall(SYS_getpid)` 직접 호출이 같은 값을 돌려주는 것, 그리고 `SYS_getpid`(39) · `SYS_write`(1) 번호를 출력한다. `syscall(SYS_write, 1, …)` 로 write 도 직접 부른다. `_GNU_SOURCE` 와 `<sys/syscall.h>` 가 필요하다.

@@ linux-d1-src-03_errno.c
예제 03 원본 소스 파일이다. `try_open()` 이 open 실패 시 `errno` 와 `strerror(errno)` 를 출력한다. /etc/hostname 성공, /no/such/file ENOENT, /etc/shadow EACCES(일반 사용자), /etc 쓰기 EISDIR, `close(100)` 은 EBADF 를 `perror` 로 보여 준다. errno 는 실패했을 때만 읽는다.

@@ linux-d1-src-04_proc_self.c
예제 04 원본 소스 파일이다. `read_status()` 가 /proc/self/status 를 fgets 로 한 줄씩 읽어 "키:" 로 시작하는 줄의 값을 꺼낸다 (콜론 뒤 공백 건너뛰기, `strcspn` 으로 줄바꿈 제거). main 은 Name · State · Pid · PPid · Threads · VmRSS 를 출력하고, 50MB 를 malloc 한 뒤 memset 으로 실제로 써서 VmRSS 가 늘어나는 것을 보여 준다. 쓰지 않으면 RSS 가 거의 안 는다 (Day 3 demand paging).

@@ linux-d1-src-05_fork_basic.c
예제 05 원본 소스 파일이다. fork 전에 fflush 로 버퍼를 비우고, 반환값으로 자식(0)과 부모(자식 PID)를 나눈다. 자식은 x+1, 부모는 x-1 해서 서로 다른 값이 나오므로 fork 뒤 메모리가 따로임(Copy-on-Write)을 보여 준다. 부모는 `wait(NULL)` 로 자식을 거둔 뒤 출력한다.

@@ linux-d1-src-06_fork_exec_wait.c
예제 06 원본 소스 파일이다. 인자가 있으면 그 명령을, 없으면 `ls -l /tmp` 를 자식에서 `execvp` 로 실행한다. exec 실패면 `_exit(127)`. 부모는 `waitpid` 후 `WIFEXITED`/`WEXITSTATUS` 로 종료 코드, `WIFSIGNALED`/`WTERMSIG` 로 시그널 번호를 출력한다.

@@ linux-d1-src-07_zombie.c
예제 07 원본 소스 파일이다. 자식은 바로 `exit(7)`, 부모는 20초 동안 wait 하지 않아 그동안 자식이 좀비(Z)로 남는다. 20초 뒤 `waitpid` 로 거두면 좀비가 사라지고 종료 코드 7 을 출력한다. `./07_zombie &` 후 `ps -o pid,ppid,stat,cmd --ppid $!` 로 관찰한다.

@@ linux-d1-src-08_orphan.c
예제 08 원본 소스 파일이다. 부모는 1초 뒤 자식을 기다리지 않고 끝나고, 3초 자는 자식은 그 사이 고아가 되어 `getppid()` 가 init(1) 또는 subreaper 로 바뀐다.

@@ linux-d1-src-09_sigaction.c
예제 09 원본 소스 파일이다. sigaction 으로 SIGINT 핸들러(횟수 증가 + write)와 SIGCHLD 핸들러(`waitpid(-1, NULL, WNOHANG)` 반복으로 모든 자식 수거, SA_RESTART)를 등록한다. 2초 뒤 끝나는 자식은 SIGCHLD 핸들러가 거두고, main 은 `pause()` 로 기다리다 Ctrl+C 3번이면 끝난다. 공유 변수는 `volatile sig_atomic_t`.

@@ linux-d1-src-Makefile
Day 1 공통 Makefile 원본이다. `$(wildcard *.c)` 로 모든 소스를 찾고 `$(SRCS:.c=)` 로 실행 파일 이름을 만든다. 패턴 규칙 `%: %.c` 의 명령 `$(CC) $(CFLAGS) -o $@ $<` 가 각 파일을 빌드한다 (-Wall -Wextra -g). `make clean` 은 실행 파일을 지우고, `.PHONY` 로 all · clean 이 파일이 아님을 알린다.

@@ linux-d1-src-check_env.sh
환경 점검 스크립트 원본(src 폴더 판)이다. 강의 본문 판과 비슷하게 배포판 · 커널, 코어 수(2 이상 권장)와 가상화 종류, WSL 여부(/proc/version 에 microsoft 면 Day 4 모듈 실습은 대체 과제), `mokutil --sb-state` 로 Secure Boot, sudo 권한, 필수 도구(gcc · make · gdb · strace · valgrind · perf · stress-ng)를 [ OK ] / [WARN] 으로 보여 주고 설치 명령을 안내한다.

@@ linux-d1-src-myshell.c
종합 실습 myshell 원본 소스 파일이다. `parse()` 가 strtok 으로 한 줄을 argv 로 자르고 끝에 NULL 을 둔다. 셸은 SIGINT 를 무시하고, 프롬프트에 직전 종료 코드를 보여 주며, Ctrl+D(fgets NULL)에서 끝난다. `exit` · `cd`(chdir, 인자 없으면 HOME)는 내장 명령으로 직접 처리하고, 나머지는 fork → 자식은 SIGINT 를 기본으로 되돌리고 execvp(실패 시 127) → 부모는 waitpid 로 종료 코드나 128 + 시그널 번호를 기록한다.

@@ linux-d1-src-run.sh
반복 측정 스크립트 원본이다. 인자가 2개 미만이면 사용법을 출력하고, 프로그램을 N회 실행하며 `date +%s%N` 전후 차이를 ms 로 바꿔 "run,elapsed_ms" CSV 에 쌓는다. 출력 파일 이름은 셋째 인자, 없으면 result.csv 이고, 끝에 결과를 cat 으로 보여 준다.
