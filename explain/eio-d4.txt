@@ eio-d4-sec1-1
I2C 트랜잭션을 비트 단위로 적은 것이다.
- 쓰기: START 뒤에 7비트 주소 1001000(0x48)과 쓰기 비트 0 을 보내고, PCF8591 이 ACK 하면 제어 바이트 0100 0000(0x40)을 보내고 다시 ACK 를 받은 뒤 STOP 한다.
- 읽기: 주소 뒤 비트를 1(R)로 보내면 장치가 바이트를 내보낸다. 마스터는 받을 때마다 ACK 하고, 마지막 바이트 뒤에는 NACK 로 "그만" 을 알린 다음 STOP 한다.

PCF8591 은 읽기 요청을 받는 순간 다음 변환을 시작하므로 첫 바이트는 지난번 변환 값이다. 그래서 2바이트를 읽고 첫 바이트를 버린다(MCU Day 3 과 같다).

@@ eio-d4-sec1-5
PCF8591(8비트 ADC 4채널 + DAC 1채널)을 다루는 헤더다. 제어 바이트는 bit6 이 DAC 출력 켜기, bit5~4 가 입력 방식(00 단일), bit2 가 자동 증가, bit1~0 이 채널 번호다.
- 상수: `PCF_ADDR` 0x48, `PCF_DAC_ON` 0x40, `PCF_AUTOINC` 0x04, `PCF_VREF_MV` 3300(모듈 Vcc 가 3V3 이라 기준 전압도 3.3 V).
- `pcf_open()`: 버스 파일을 O_RDWR 로 열고 `ioctl(fd, I2C_SLAVE, addr)` 로 상대 주소를 정한다. 이후 read · write 는 모두 이 주소로 간다. 실패하면 perror 후 -1.
- `pcf_read()`: 제어 바이트 `0x40 | ch` 를 1바이트 쓰고 2바이트를 읽어 두 번째 바이트(buf[1])를 돌려준다. 첫 바이트는 이전 변환 값이라 버린다.
- `pcf_read_all()`: 제어 0x44(DAC 켜기 + 자동 증가 + 채널 0)를 쓰는 메시지와 5바이트를 읽는 메시지(`I2C_M_RD`)를 `struct i2c_msg` 두 개로 만들어 `ioctl(I2C_RDWR)` 한 번에 넘긴다. 쓰기와 읽기 사이에 STOP 없이 다시 시작하므로 한 트랜잭션이 되고, buf[0] 을 버린 buf[1]~buf[4] 가 AIN0~3 이다.
- `pcf_write_dac()`: {0x40, value} 2바이트를 써서 AOUT = value/255 × Vref 로 만든다.
- `pcf_mv()`: raw × 3300 / 255 로 0~255 를 mV 로 바꾼다.

@@ eio-d4-sec1-t1
MCU 의 Wire 코드와 Linux 코드를 하는 일별로 짝지은 표다. 버스 시작 `Wire.begin(21, 22)` 은 `open("/dev/i2c-1", O_RDWR)`, 상대 고르기 `Wire.beginTransmission(0x48)` 은 `ioctl(fd, I2C_SLAVE, 0x48)`, 바이트 쓰기 `Wire.write(0x40); Wire.endTransmission()` 은 `write(fd, &ctrl, 1)`, 바이트 읽기 `Wire.requestFrom(0x48, 2); Wire.read()` 는 `read(fd, buf, 2)`, 장치 찾기 스캐너 스케치는 `i2cdetect -y 1` 에 해당한다.

@@ eio-d4-sec1-t2
I2C 용어 정리 표다. SDA · SCL 두 선(데이터 · 클럭)에 여러 장치를 함께 달고, 장치마다 7비트 주소가 있다(PCF8591 = 0x48). 두 선은 풀업으로 평소 High 이고 장치는 Low 로 끌어내리기만 한다(Day 2 의 open-drain). 받는 쪽은 바이트 하나를 받을 때마다 SDA 를 Low 로 당겨 ACK 를 알리고, SCL 이 High 일 때 SDA 가 내려가면 START, 올라가면 STOP 이다.

@@ eio-d4-sec2-t1
PCF8591 제어 바이트의 비트별 뜻이다. bit7 과 bit3 은 0, bit6 은 DAC 출력 켜기, bit5 · 4 는 입력 방식(00 = 단일 입력 4채널), bit2 는 자동 증가, bit1 · 0 은 채널 번호다. 그래서 0x40 은 DAC 켜기 + 채널 0, 0x44 는 여기에 자동 증가를 더한 값이다.

@@ eio-d4-sec1-t3

@@ eio-d4-src-Makefile
Day 4 의 Makefile 원본이다. Day 1~5 가 함께 쓰는 공통 템플릿으로, gcc 에 `-Wall -Wextra -O2 -g` 와 pkg-config 의 libgpiod 플래그를 주고 LDLIBS 에 libgpiod · `-lpthread` · `-lm` 을 링크한다. 폴더의 .c 를 모두 BINS 로 삼아 `make` 는 전부, `make 이름` 은 하나만 빌드하고, `%: %.c $(wildcard *.h)` 규칙으로 헤더가 바뀌어도 다시 빌드한다. `make clean` 은 실행 파일을 지운다.
