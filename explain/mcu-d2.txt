@@ mcu-d2-sec1-1
가변저항 전압을 `analogRead` 로 읽어 숫자로 출력한다. ESP32 ADC 는 12비트라 0~4095(2¹² = 4096 단계)를 돌려준다 (Arduino Uno 는 10비트 0~1023). 손잡이를 왼쪽 끝으로 돌리면 0 근처, 오른쪽 끝이면 4095 다. analogRead 가 핀을 ADC 로 설정하므로 `pinMode` 는 필요 없다.

@@ mcu-d2-sec1-2
같은 핀을 세 가지로 읽어 비교한다. `analogRead` 는 ADC 가 낸 숫자 그대로, `analogReadMilliVolts` 는 칩 안 보정값(eFuse)으로 계산한 mV, `naive` 는 `raw * 3300 / 4095` 단순 비례 계산이다. ADC 는 칩마다 차이가 있고 양 끝에서 비선형이라 단순 비례는 틀어진다. 전압이 필요하면 analogReadMilliVolts 를 쓴다.

@@ mcu-d2-sec1-3
ADC 를 n 번 읽어 평균을 돌려주고, 최소 · 최대는 포인터 인자로 돌려준다.
- 반환값은 하나뿐이라 여러 결과는 호출자가 넘긴 주소(`&mn`, `&mx`)에 `*min_out = mn;` 처럼 써 준다 (C 과정 max_to 모양).
- `mn` 은 가장 큰 값 4095, `mx` 는 0 에서 시작해 더 작은/큰 값으로 바꾼다. 합은 넘치지 않게 `long` 에 모은다.
- `noise = mx - mn` 은 흔들림의 폭이다. 손을 대지 않아도 수십이 나오는 것이 정상이고 2교시 필터로 줄인다.

@@ mcu-d2-sec1-4
배열에 모은 ADC 값 16개의 최소 · 최대 · 평균을 포인터 인자로 한 번에 구한다.
- 빈칸 ① `*mx`: 지금 값이 지금까지의 최대보다 크면 최대를 바꾼다.
- 빈칸 ② `*avg`: 평균을 호출자의 변수에 써 준다. `(float)sum / n` 으로 실수 나눗셈.
- 빈칸 ③ `PIN_POT`: 34번 가변저항 핀을 읽는다.
- 빈칸 ④ `&avg`: 평균을 받을 변수의 주소를 넘긴다.
배열은 넘기면 포인터(`const int *a`)가 되므로 길이 n 을 따로 넘기고, `const` 는 '읽기만 한다' 는 약속이다.

@@ mcu-d2-sec1-t1
ADC 값을 다룰 때 알아야 할 세 가지다. `analogRead` 는 ADC 숫자 그대로라 칩마다 조금씩 다르고 0V 근처 · 3.1V 이상에서 비선형이다. `analogReadMilliVolts` 는 칩의 eFuse 보정값으로 계산한 mV 라 전압이 필요하면 이것을 쓴다. 감쇠(attenuation) 기본 11dB 에서는 약 0.15V ~ 3.1V 를 잴 수 있고 그 밖은 0 또는 4095 로 붙는다.

@@ mcu-d2-sec1-t2
ADC 함정 표다.
- 가변저항을 GPIO 25(ADC2)에 달면 지금은 읽히지만 Day 4 에서 Wi-Fi 를 켜면 값이 안 나온다. ADC 는 처음부터 ADC1(32~39)에 단다.
- 가변저항 끝을 5V 에 달면 3.1V 이상 구간이 계속 4095 이고, 핀에 3.3V 를 넘는 전압이 들어가 손상될 수 있다.
- 가운데 다리가 아닌 끝 다리를 GPIO 에 달면 돌려도 0 이나 4095 에서 안 변한다.

@@ mcu-d2-sec1-p1-2
ADC 기초를 확인하는 괄호 넣기다.
1. ESP32 ADC 는 12비트라 2¹² − 1 = 4095 까지.
2. 칩마다 보정된 mV 를 주는 함수는 `analogReadMilliVolts`.
3. Wi-Fi 와 같이 쓸 수 있는 것은 ADC1 이고 GPIO 32 ~ 39 다 (ADC2 는 Wi-Fi 가 쓴다).
4. 가변저항은 가운데 다리(와이퍼)에서 돌린 위치에 따른 전압이 나오므로 그 다리를 GPIO 에 연결한다.

@@ mcu-d2-pdf-p9-1

@@ mcu-d2-sec2-1
조도 센서(포토레지스터, CdS) 값을 읽어 시리얼 플로터에 그린다. 포토레지스터는 밝으면 저항이 작아지고 어두우면 커진다. ADC 는 저항을 직접 못 재므로 10kΩ 과 직렬로 이어 가운데 전압 Vout = 3.3V × R_10k ÷ (R_photo + R_10k) 을 35번 핀으로 읽는다. 밝으면 값이 커지고 손으로 가리면 작아진다. `Serial.printf("light:%d\n", raw)` 처럼 `이름:값` 형식으로 출력하면 시리얼 플로터에 이름이 범례로 나온다.

@@ mcu-d2-sec2-2
링 버퍼 이동평균으로 ADC 값의 흔들림을 줄인다.
- `ring_t` 는 최근 RN(8)개 값 `buf`, 다음에 쓸 위치 `head`, 들어온 개수 `count`(최대 RN), 합계 `sum` 을 담는다.
- `ring_push()` 는 버퍼가 가득 찼으면 head 자리(가장 오래된 값)를 합계에서 빼고, 아니면 count 를 늘린다. 새 값을 head 에 쓰고 합계에 더한 뒤 `head = (head + 1) % RN` 으로 한 칸 옮긴다. 끝에 닿으면 0 으로 돌아가 고리처럼 돈다.
- 합계를 들고 다니므로 RN 이 커져도 계산은 더하기 한 번 · 빼기 한 번이다. 평균은 `sum / count`.
- `raw:%d,avg:%d` 로 두 줄을 플로터에 함께 그려 필터 효과를 본다.

@@ mcu-d2-sec2-3
조도 센서로 어두울수록 LED 를 밝게 켜는 자동 조명이다. 링 버퍼로 평균 낸 조도 `avg`(0~4095)를 `duty = 255 - avg * 255 / 4095` 로 뒤집어 0~255 듀티로 바꾼다. 어두울수록(avg 작을수록) duty 가 크다. duty 가 20 미만(충분히 밝음)이면 0 으로 꺼 버린다. Day 1 의 `ledcAttach` / `ledcWrite` 로 25번 LED 밝기를 쓴다.

@@ mcu-d2-sec2-4
링 버퍼 `ring_push()` 를 완성하는 빈칸이다.
- 빈칸 ① `r->head`: 가득 찼을 때 head 자리가 가장 오래된 값이라 그 값을 합계에서 뺀다.
- 빈칸 ② `v`: 새 값을 합계에 더한다.
- 빈칸 ③ `RN`: `(head + 1) % RN` 으로 끝에 가면 0 으로 돌아간다.
- 빈칸 ④ `count`: 가득 차기 전에는 들어온 개수로 나눠야 처음 몇 개도 올바른 평균이 된다.

@@ mcu-d2-sec2-t1
조도별 포토레지스터 저항과 분압 결과다. 손전등처럼 밝으면 약 1kΩ → Vout 3.0V → raw 약 3700, 실내는 10kΩ → 1.65V → 약 2000, 손으로 가리면 100kΩ → 0.3V → 약 300. 식 Vout = 3.3 × 10k ÷ (R_photo + 10k) 그대로다.

@@ mcu-d2-sec2-t2
조도 센서 함정 표다.
- 10kΩ 없이 포토레지스터만 3V3 ↔ GPIO 에 달면 GPIO 가 3V3 에 거의 직결되어 밝기와 상관없이 4095 근처다.
- 10kΩ 대신 220Ω 을 쓰면 가운데 전압이 거의 0 이라 항상 작은 값이다 (10kΩ 색띠는 갈색 검정 주황).
- LED 를 센서 바로 옆에 두면 LED 빛이 센서로 들어가, 켜지면 밝다고 판단해 끄고 꺼지면 다시 켜는 진동이 생긴다.

@@ mcu-d2-sec2-p2-2
조도 센서와 필터를 확인하는 괄호 넣기다.
1. 포토레지스터는 빛이 많을수록 저항이 작아진다.
2. 고정 저항과 직렬로 이어 가운데 전압을 읽는 회로가 전압 분배(분압) 회로다.
3. `(head + 1) % RN` — 나머지 연산으로 끝에서 0 으로 돌아간다.
4. 시리얼 플로터는 `이름:값` 형식에서 이름을 범례로 쓴다.

@@ mcu-d2-sec3-1
조이스틱의 X · Y(아날로그)와 버튼 SW(디지털)를 읽어 플로터에 그린다. X 는 GPIO 36(VP), Y 는 39(VN)에서 analogRead 로 0~4095 를 읽고, SW 는 `INPUT_PULLUP` 이라 누르면 LOW 다. sw 를 0/1 로 만든 뒤 4095 를 곱해 같은 그래프 크기로 보이게 한다. 가운데 값은 정확히 2048 이 아니고 제품마다 달라 약 1800~2000 이므로, 처음에 가운데 값을 재서 저장해 두는 것이 좋다.

@@ mcu-d2-sec3-2
라이브러리 없이 LEDC 로 서보(SG90) 각도를 정한다. 서보는 20ms(50Hz)마다 오는 펄스의 HIGH 길이로 각도를 정한다: 약 0.5ms = 0°, 1.5ms = 90°, 2.5ms = 180°.
- `ledcAttach(PIN_SERVO, 50, 14)`: 50Hz(주기 20ms), 14비트(0~16383) PWM. 14비트면 한 단계가 약 1.2µs 라 각도를 부드럽게 줄 수 있다 (8비트는 한 단계 78µs 라 너무 거칠다).
- `servo_write_us(us)`: 펄스 폭 us 를 `us * MAX_DUTY / 20000` 듀티로 바꾼다. 1500µs 는 20ms 의 7.5%.

초음파 센서 HC-SR04 로 거리를 잰다.

- `pulseIn(PIN_ECHO, HIGH, 30000)` 은 Echo 가 HIGH 인 시간(µs)을 재며, 최대 30ms 만 기다린다. 0 이면 타임아웃(범위 밖)이라 −1 을 돌려준다.

- 세 번째 인자(타임아웃)를 빼면 물체가 없을 때 1초 동안 멈춘다. Echo 는 5V 라 10k : 20k 로 분압해 GPIO16 에 넣는다.

- 빈칸 ① `ifndef`: `#ifndef SENSOR_H` 로 include guard 를 시작한다. 처음 포함될 때만 SENSOR_H 가 정의되지 않았으므로 내용이 들어간다.
- 빈칸 ② `extern`: '메모리는 다른 곳(sensor.cpp)에 있다' 는 선언이라 여러 파일에 포함되어도 충돌하지 않는다.

@@ mcu-d2-sec7-t1

@@ mcu-d2-sec7-t2
파일 분리 때 나는 링크 오류 읽는 법이다.
- 헤더에 `int sensor_read_count = 0;`(정의)를 두면 포함한 파일마다 정의가 생겨 `multiple definition` 오류. 헤더에는 extern 선언만.
- sensor.cpp 에서 정의를 지우면 선언만 있고 실체가 없어 `undefined reference` 오류.
- include guard 없이 헤더를 두 번 포함하면 같은 typedef 가 두 번이라 `redefinition of 'struct …'` / `conflicting declaration`.
- 탭 이름을 sensor.c 로 만들면 .c 는 C, .ino 는 C++ 로 컴파일되어 이름 규칙이 달라 undefined reference. .cpp 로 통일한다.
multiple definition · undefined reference 는 링커(ld, collect2)가 내는 오류다.

2. 함수 원형 · extern 선언은 .h 에, 함수 몸체는 .cpp 에 둔다.
3. undefined reference 는 이름을 잇는 링크 단계 오류라 링커가 낸다.
4. 헤더가 두 번 포함돼도 한 번만 처리되게 하는 #ifndef … #endif 가 include guard 다.

8교시(다중 센서 모니터)와 Day 2 정리 본문에 나온 코드 조각이다.
- `table[current]()`: Day 1 의 함수 포인터 상태 표 호출. 센서 표가 같은 발상이다.
- `loop`: 표를 돌기만 하는 함수가 된다.
- `multi_monitor.ino`: 8교시 종합 과제 스케치.
- `sensor_t`: 이름 · 읽기 함수 포인터 · 값 · 주기를 담는 센서 구조체.
- `ring_t`: 2교시 링 버퍼. 확장 과제에서 sensor_t 멤버로 붙여 필터를 적용한다.
- `alarm_t`: 5교시 히스테리시스 경보. 확장 과제에서 LM35 30°C 경보에 쓴다.
- `delay`: 전체를 늦추지 않도록 쓰지 않고 millis 주기 비교를 쓴다.
- `analogReadMilliVolts`: LM35 를 mV 로 읽는 함수.
- `.h`: 선언을 두는 헤더 (Day 2 정리: 선언은 .h).
- `.cpp`: 정의를 두는 소스 (정의는 .cpp).
- `extern`: 파일 사이에서 공유하는 전역 변수 선언.
