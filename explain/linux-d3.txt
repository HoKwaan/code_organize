@@ linux-d3-sec3-1

@@ linux-d3-sec4-t1

@@ linux-d3-sec4-p4-2

2. MAP_SHARED 는 page cache 를 직접 고쳐 파일에 반영된다.
3. MAP_PRIVATE 에 쓰면 그 순간 내 복사본이 생긴다.
4. 매핑은 fd 를 닫아도 munmap 할 때까지 유지된다.

@@ linux-d3-sec5-2

@@ linux-d3-sec5-3

- 빈칸 ② `0`: fork 가 0 을 돌려준 쪽이 자식이다.
- 빈칸 ③ `100`: 쓸 범위 = SIZE × pct / 100.
- 빈칸 ④ `wait`: 부모가 자식이 끝날 때까지 기다려 거둔다.

@@ linux-d3-sec5-p5-2

3. Copy-on-Write 의 약자는 COW 다.

@@ linux-d3-sec6-t1

@@ linux-d3-sec6-p6-2

@@ linux-d3-sec7-t1

예제 05 원본 파일이다. 부모가 50MB 를 채운 뒤 fork 하고, 자식이 인자 % 만큼 페이지마다 써서 minor fault 증가량(= 복사된 페이지 수)을 출력한다. 부모의 값은 그대로임을 확인한다.

@@ linux-d3-src-06_mlock.c
예제 06 원본 파일이다. lock 인자면 mlockall(MCL_CURRENT | MCL_FUTURE) 로 잠근 뒤 32MB 를 malloc 하고, malloc 중과 루프 중의 fault 수, 루프 시간, VmLck 를 출력해 잠금 효과를 비교한다.

@@ linux-d3-src-07_oom.c
예제 07 원본 파일이다. overcommit_memory 값을 출력한 뒤 10MB 씩 malloc 하고 memset 으로 실제로 써 가며 VmRSS 를 출력한다. cgroup 한도(MemoryMax=100M) 안에서 실행하면 OOM killer 에게 Killed 된다.

@@ linux-d3-src-08_bugs.c
예제 08 원본 파일이다. leak · use_after_free · overflow · double_free 네 함수가 각각 메모리 오류를 일부러 만들고, 인자로 하나를 골라 실행한다. valgrind 나 ASan 빌드(08_bugs_asan)로 잡아 본다.

@@ linux-d3-src-Makefile
Day 3 공통 Makefile 이다. 모든 .c 를 `-Wall -Wextra -g` 로 같은 이름의 실행 파일로 빌드한다. 추가로 `make asan` 은 08_bugs.c 를 `-fsanitize=address` 로 빌드해 08_bugs_asan 을 만들고, `make clean` 은 실행 파일을 지운다.

@@ linux-d3-src-memlab.c
memlab 원본 파일이다. demand · cow · mmap · lock 실험 중 하나와 크기(MB)를 받아, `touch` 로 페이지마다 쓰고 `row` 로 `exp,size_mb,minflt,majflt,rss_kb,ms` CSV 한 줄을 출력한다. 잘못된 인자면 사용법을 보여 준다.

@@ linux-d3-src-memlab_run.sh
memlab 반복 실행 스크립트 원본이다. demand · cow · mmap 을 N번(기본 5)씩 실행해 CSV(기본 memlab.csv)에 모으고, sudo 가 가능하면 lock 도 실행한다. 끝에 `column` 으로 표처럼 보여 준다.

@@ linux-d3-src-memutil.h
Day 3 공용 헤더 원본이다. `status_kb`(/proc/self/status 항목 kB), `minflt` · `majflt`(getrusage 의 page fault 수), `now_ms`(MONOTONIC ms) 네 함수를 static inline 으로 제공한다.
