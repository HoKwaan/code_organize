Embedded I/O 강의 코드에서 libgpiod v2 함수와 상수를 쓰는 줄을 하나씩 모은 표다. 줄마다 오른쪽 주석에 뜻과 출처(Day · 교시)가 있다. 쓰는 순서대로 묶으면 다음과 같다.
- 칩 열기 · 닫기: `gpiod_chip_open("/dev/gpiochip0")`, `gpiod_chip_close(chip)`.
- 라인 설정: `gpiod_line_settings_new()` 로 만들고 `set_direction`(INPUT / OUTPUT), `set_output_value`(ACTIVE / INACTIVE), `set_bias`(PULL_UP / PULL_DOWN / DISABLED), `set_edge_detection`(FALLING / BOTH), `set_debounce_period_us`, `set_active_low` 로 채운다.
- 요청: `gpiod_line_config_new()` + `gpiod_line_config_add_line_settings`(라인 번호에 설정 붙이기), `gpiod_request_config_new()` + `set_consumer`(gpioinfo 에 보일 이름), 그리고 `gpiod_chip_request_lines` 로 커널에 요청한다.
- 값 읽기 · 쓰기: `gpiod_line_request_get_value`, `gpiod_line_request_set_value`(하나), `gpiod_line_request_set_values`(여러 개).
- 엣지 이벤트: `gpiod_line_request_get_fd` 로 poll/epoll 용 fd 를 얻고, `gpiod_edge_event_buffer_new` 버퍼에 `gpiod_line_request_read_edge_events` 로 읽어 `gpiod_edge_event_buffer_get_event` 로 하나씩 꺼낸다. 이벤트에서 시각(`get_timestamp_ns`), 종류(`get_event_type`: FALLING_EDGE / RISING_EDGE), 라인 번호(`get_line_offset`)를 얻는다.
- 정리: `gpiod_line_request_release` 로 라인을 반납한다. `poll(&p, 1, ms)` 는 이벤트가 올 때까지 기다리며 0 이면 시간 초과다.
